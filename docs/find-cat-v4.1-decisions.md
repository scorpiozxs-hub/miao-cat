# V4.1 已确认决策

来源：[最新策划](https://app.notion.com/p/406045159e18809bb54dceb9fe915dc7)，2026-10-28 会话确认。

- React＋Canvas 2D＋ONNX Worker 重写 H5，保留 Godot 预览作为历史版本，不继续使用 Godot 引擎。
- 提交采用最终画面的真实本地整数分 `Math.round(p*100)>50`，不做服务端模型推理。实时平滑值不解锁旧图。
- 50项阵容：目标1项＋其他云端公开画作49项；不足时均匀重复，目标及相同像素哈希不得重复。没有合格干扰作品时不开始正式局。
- 每次新命名提交生成独立playerId，绑定技术鉴权authUid；同次请求重试复用playerId与artworkId。不按设备、昵称或authUid合并榜位。
- 内容检查、图像格式/可见笔迹检查、服务端计时、会话归属和事务幂等仍保留。
- 首版通过云函数代理2MB以内的PNG上传，数据库、存储均拒绝客户端直读直写，避免宽泛上传权限。图片与文本通过检查后才进入公开池。
- 正式模型和云环境未就绪时允许绘画、草稿和明确标注的本机练习；不发布作品、不生成正式成绩、不补假榜单。

限制：本地评分可被修改，新身份可重复占榜。该版本属于休闲挑战，不能声称竞技防作弊或每个自然人唯一排名。
